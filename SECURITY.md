# Security Policy

## Supported versions

Security fixes are generally applied to the latest released version and the current `main` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's [Private Vulnerability Reporting](https://github.com/Taniuchi-Taiyo/Bunken/security/advisories/new) if it is enabled for this repository. If that option is unavailable, contact the repository maintainers through a private GitHub channel and include:

- a clear description of the vulnerability;
- affected versions or commits;
- steps to reproduce or a proof of concept; and
- the potential impact.

Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing the issue. Do not include real user libraries, personal information, private PDFs, or credentials in a report.

## Scope

Reports involving data exposure, unsafe file handling, cross-site scripting, malicious document processing, dependency vulnerabilities, or other behavior that could compromise users or their data are in scope.

## Response

Maintainers will acknowledge a valid report as soon as practical, investigate its impact, and coordinate a fix or mitigation. Reporter credit will be given when requested and appropriate.
